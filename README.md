# API Challenges

A basic [Bruno](https://www.usebruno.com/) collection that demonstrates Bruno's core concepts using the [API Challenges](https://apichallenges.com/api/docs) API to implement a simple to-do list manager.

## Getting started

Start by sending the **Create Challenger** request to create a challenger (a session ID) that you can use to interact with the API.

Once the challenger has been created, you can use the other requests in the collection to manage your to-do list.
